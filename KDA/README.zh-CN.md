# KDA 工作流

[English](README.md) · **简体中文**

面向竞赛/工程落地场景的证据驱动内核优化流程，实现 Kernel Design Agents（KDA）方法：草案 → 计划 → 实现 → 验证 → 决策 → 记录。

## 核心原则

- 任务契约优先（目标、约束、验证命令、晋升标准）
- 一次只推进一个候选方案
- 所有“拒绝/失败”都记录原因，避免重复踩坑
